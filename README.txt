BLOCK BLAST (basic) - PHP + XAMPP

1. Open XAMPP and start Apache.
2. Extract the "blockblast" folder into:  C:\xampp\htdocs\
3. Open your browser:  http://localhost/blockblast/

Files:
  index.php        main page
  api/score.php    saves/reads the best score
  assets/          style.css, game.js
  data/score.json  best score storage

How to play: drag the 3 blocks onto the 8x8 grid. Full rows/columns clear.
The game ends when none of the remaining blocks fit.
